# Origin-RAG System Architecture Specification

## 1. Executive Overview
Origin-RAG is designed to eliminate AI hallucination by establishing 100% verifiable source attribution.
Every answer generated by the engine includes precise line-range citations referencing raw source documents.

## 2. Core Components
The system consists of five primary layers:
- Document Parsing & Line Tracking Engine
- Overlapping Boundary Semantic Chunker
- Dense-Sparse Hybrid Retriever with Reciprocal Rank Fusion
- Verification & N-Gram Attribution Scoring Engine
- FastAPI Microservice & CLI Interface

## 3. Attribution Formula
Attribution coverage is calculated using n-gram overlap against retrieved context chunks:
Coverage = (Attributed N-Grams) / (Total Generated Answer N-Grams)
If coverage falls below 0.70, the engine flags a Hallucination Warning.
